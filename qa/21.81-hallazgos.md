  stock de pulseras; pestañas "Pulseras" y "Materia prima").
- REG-HAL-26 en adelante: commit `8a2311b` (2026-11-25), que agrega `backend/`: API en

  desde el backend. Corrida y evidencia en `ejecuciones/21.81-evidencia-2026-11-25.md`.

## Cómo se usa
- Cada hallazgo toma el siguiente ID libre (`REG-HAL-NN`). Un ID no se recicla.
- Tipo: `defecto`, `documentación`, `arranque`, `duda`, `seguridad`.
- Estado: `por verificar`, `confirmado`, `descartado`, `reportado`, `cerrado`;
  `reparado`: corregido en la rama `fix/hallazgos-qa` del repositorio. REG-HAL-01 a 25
  se integraron a `develop` el 2026-11-24. Las reparaciones del 2026-11-25 se publicaron ese
  día en la misma rama, con un pull request contra `develop`, sin integrar.
- Lo que surge de leer el código entra como `por verificar`. Pasa a `confirmado` con
  pasos, resultado esperado, resultado obtenido y evidencia.
